# ЕТОР

Рабочий репозиторий разработки бренда «Единая территория опережающего развития».

Первый этап: самостоятельный логотип и базовая айдентика. Развитие: зонтичный бренд. Проект связан с КРДВ, но ее брендинг не используется как визуальная основа.

По поручению Сергея от 3 ноября 2026 года здесь сохраняются контекст, исходные материалы, решения, варианты, обратная связь и ход работы.

Текущий этап: фиксация исходного контекста и предварительного разбора презентации. Логотип, палитра, шрифты и состав суббрендов пока не утверждены.
