# ЕТОР

Рабочий репозиторий бренда «Единая территория опережающего развития». Самостоятельный логотип с перспективой зонтичной системы. КРДВ учитывается как контекст проекта, ее брендинг не используется.

По поручению Сергея здесь сохраняются доступный контекст, процесс, варианты, запросы и обратная связь.

## Актуальный статус, 3 ноября 2026

**Отдельный знак обязателен. Только современная стилистика, без ретро. Каждый вариант показывается отдельным презентационным слайдом с айдентикой и примерами.**

Пользователь отрицательно оценил предыдущую серию: «нужно что0то нормальное, современное, у тебя сейчас варианты несурахные». Варианты 01-09 сохранены как история исследования, текущим предложением не являются.

После замечания подготовлены две новые раскладки:

| Вариант | Слайд | Характер |
| --- | --- | --- |
| 01. Точка входа | [PNG](concepts/10-entry-point/v01/brand-board.png) | Черный и лайм, компактная монограмма, плоские макеты сайта и путеводителя |
| 02. Пространство возможностей | [PNG v02](concepts/11-project-space/v02/brand-board.png) | Темно-фиолетовый и сиреневый, абстрактный знак, более легкая типографика |

[PDF с двумя новыми вариантами](output/pdf/ETOR-brand-concepts-rework-2026-11-03.pdf).

Это растровые концепции для выбора направления. Ни логотип, ни цвета, ни шрифты, ни состав зонтика пока не утверждены. Рекомендация исполнителя: первым обсуждать «Точку входа». Это не решение заказчика.
