Палитра, знак ЕТ, слоган и подпись зонтика предложены исполнителем. Это растровая концепция, а не готовые производственные исходники. Знак требует дальнейшей индивидуализации и проверки малых размеров. По сравнению с предыдущими сериями подача стала яснее, но сама по себе аккуратность не доказывает достаточную отличимость бренда.
