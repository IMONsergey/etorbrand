# Общее поле

Статус: архив после общей отрицательной оценки предыдущей серии пользователем. Не продолжать как утвержденное направление.

[Слайд](v01/brand-board.png). [Точный промпт](v01/prompt.md).

Одна концепция на слайде: знак с названием, идея, фирменный прием, палитра, типографический образец, сайт и печатные материалы. Фактический растр 1672 x 941, близко к 16:9. Запрошенное 2560 x 1440 генератор не выдал.

Оценка исполнителя после критики: чрезмерно тяжелая корпоративная пластика, шаблонная подача, недостаточная самостоятельность знака. Не приписывать пользователю выборочные комментарии по деталям, он оценил серию в целом.
