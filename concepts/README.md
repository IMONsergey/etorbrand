# Концепции и версии

На 3 ноября 2026 года визуальных вариантов в репозитории нет. H01-H03 в брифе являются направлениями исследования.

Для каждого варианта создавать отдельную папку, например `01-wordmark/v01/`. Это пример структуры, не утвержденное название концепции.

Внутри сохранять:

- `README.md`: идея, статус, ограничения, дата, состав файлов, источник обратной связи.
- `source/`: редактируемые исходники и необходимые зависимости.
- `exports/`: проверенные изображения и файлы для просмотра.
- `prompts.md`: точные запросы и настройки генерации, если она применялась.
- `feedback.md`: комментарии пользователя, решения и причины изменений.

Статусы: исследование, предложено, доработка, выбрано пользователем, отклонено, финал. Статусы «выбрано» и «финал» не назначать без подтверждающего решения.

Каждый визуальный вариант сохранять отдельно. Не перезаписывать старый экспорт новым под тем же именем, если это уничтожает возможность сравнения. Не включать в публичный репозиторий чужие платные шрифты и лицензируемые исходники без права распространения.
