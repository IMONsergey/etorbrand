## 2. Концепции

- [ ] Разработать три содержательно разных направления, а не три декоративные вариации одного знака.
- [ ] Для каждого показать самостоятельный логотип.
- [ ] Проверить обложку путеводителя и плотную информационную страницу.

- [ ] Проверить условное расширение семейства и монохромную версию.
- [ ] Сохранить исходники, изображения, промпты и объяснение каждого варианта.

Результат: сравнимые концепции на одинаковом наборе носителей. Изображения каждого варианта хранить отдельно.

## 3. Выбор и развитие

- [ ] Записать обратную связь пользователя по каждому варианту.
- [ ] Зафиксировать выбранный принцип и причины отказа от остальных.
- [ ] Доработать кириллицу, оптические отношения, интервалы и композиции.
- [ ] Проверить малый размер, один цвет, инверсию, длинные подписи и различимость членов семейства.
- [ ] Проверить уникальность по релевантным визуальным аналогам; не выдавать такую проверку за юридическую регистрацию товарного знака.

Результат: согласованная основа айдентики.

- [ ] Определить палитру, типографику, сетки, графический прием и принципы изображений.

- [ ] Подготовить требуемые шаблоны и версии логотипа.

- [ ] Записать права/лицензии на использованные шрифты и сторонние материалы.
- [ ] Подготовить руководство и обновить итоговый статус проекта.

Результат: комплект, пригодный для дальнейшего самостоятельного использования. Конкретный перечень форматов и носителей согласуется отдельно.
